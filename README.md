# Руська проти слономошок!

Браузерна аркада. Торкайся мошок на телефоні або клацай по них мишею. Гра підтримує портретну й альбомну орієнтації та зберігає найкращий рахунок у браузері.

## Запуск

Відкрий гру за адресою, яку показує **Settings → Pages**. Для локальної перевірки запусти `python -m http.server 8000` з кореня репозиторію та відкрий `http://localhost:8000/docs/`. Запуск із файлової системи теж можливий, але встановлення й офлайн-кеш потребують HTTPS або localhost.

На Android відкрий гру в Chrome, натисни **⋮ → Додати на головний екран → Установити**. На iPhone відкрий гру в Safari, натисни **Поділитися → На початковий екран** і вибери **Відкрити як вебпрограму**, якщо Safari пропонує цей перемикач. Для гри офлайн один раз відкрий сторінку з інтернетом.

## Публікація й оновлення

- `docs/index.html` містить гру та звук, `docs/icons/` містить іконки, `docs/manifest.webmanifest` описує встановлення, а `docs/sw.js` відповідає за офлайн-кеш.
- GitHub Pages публікує папку `/docs` з гілки `main`. Початкова версія – **1.0.0**.
- Для оновлення відкрий цей репозиторій у Codex і попроси внести потрібні зміни. Перед публікацією онови номер у `VERSION` і `docs/sw.js`, перевір гру, закоміть і відправ зміни в `main`. Після завершення розгортання відкрий URL із **Settings → Pages** і перевір нову версію.
- При відкритті з інтернетом гра спочатку запитує актуальні файли. Нова версія офлайн-кешу активується після повного завантаження ресурсів. Уже відкритий раунд продовжується, а наступне відкриття сторінки завантажує новий код.
- Для майбутнього порталу Games додай посилання на сторінку цієї гри. Кожна гра може публікуватися зі свого репозиторію.
