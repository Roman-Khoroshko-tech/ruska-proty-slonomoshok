# Руська проти слономошок!

Браузерна аркада. Торкайся мошок на телефоні або клацай по них мишею. Гра підтримує портретну й альбомну орієнтації та зберігає найкращий рахунок у браузері.

Поточна версія — **1.0.4**.

## Запуск

Опубліковану гру відкривай за адресою з **Settings → Pages**. Для локальної перевірки запусти з кореня репозиторію:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Відкрий `http://127.0.0.1:8000/docs/`. Для встановлення й офлайн-кешу використовуй опубліковану сторінку через HTTPS або локальний сервер на цьому ж пристрої.

На Android відкрий гру в Chrome, натисни **⋮ → Додати на головний екран → Установити**. На iPhone відкрий гру в Safari, натисни **Поділитися → На початковий екран** і вибери **Відкрити як вебпрограму**, якщо Safari пропонує цей перемикач. Для гри офлайн спочатку відкрий сторінку з інтернетом і дочекайся, поки service worker завантажить ресурси.

## Структура

GitHub Pages публікує папку `/docs` з гілки `main`.

- `docs/index.html` містить гру та звук.
- `docs/manifest.webmanifest` задає назву, іконки та параметри встановлення.
- `docs/icons/ruska/` містить іконки для браузера та головного екрана.
- `docs/sw.js` попередньо кешує гру, маніфест та іконки для роботи офлайн.

## Публікація й оновлення

1. Перед наступним релізом запиши однаковий новий номер у `VERSION`, у рядку «Поточна версія» в `README.md` та в `const version` у `docs/sw.js`. Service worker використовує цей номер у назві офлайн-кешу.
2. Якщо змінюються назви чи шляхи ресурсів, звір посилання в `docs/index.html` і `docs/manifest.webmanifest` зі списком `assets` у `docs/sw.js`.
3. Перевір локальний запуск. Після першого завантаження дочекайся активації service worker, увімкни режим **Offline** в інструментах розробника та відкрий гру повторно.
4. Після погодження закоміть зміни й відправ їх у `main`. Коли GitHub Pages завершить розгортання, перевір гру за опублікованою адресою.
